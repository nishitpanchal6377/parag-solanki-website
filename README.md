# Parag Solanki — Personal Website

A static site (plain HTML/CSS/JS — no build step, no dependencies) for
Parag Solanki, Acceleration Manager at i-Hub Gujarat.

## Structure
- `index.html` — all page content
- `css/style.css` — design tokens, layout, animations
- `js/script.js` — scroll reveals, animated counters, mobile nav, magnetic button
- `assets/portrait.jpeg` — headshot used in the hero section

## Local preview
Just open `index.html` in a browser, or run:
```
python3 -m http.server 8080
```
then visit http://localhost:8080

## Deploy
See the step-by-step GitHub + Vercel guide provided alongside this project
to publish it at paragsolanki.vercel.app.
